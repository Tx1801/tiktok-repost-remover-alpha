
# TikTok Repost Remover

A Chrome extension developed to automate the removal of reposts on TikTok.

## Features

- Automatically detects the repost removal button.
- Removes reposts through the TikTok interface.
- Automatically navigates to the next video.
- Displays a counter of removal actions.

## Technologies

- HTML
- CSS
- JavaScript
- Chrome Extensions Manifest V3

## Installation

1. Download or clone this repository.
2. Open Google Chrome.
3. Navigate to `chrome://extensions/`.
4. Enable Developer mode.
5. Click "Load unpacked".
6. Select the project folder.
